# Power Distribution Fault Localization

This is a clean, modular, and interview-defensible fault localization system for an electricity distribution board.

## Architecture

- **Client:** React, Vite, TypeScript, Leaflet map.
- **Server:** Node.js, Express, TypeScript.
- **Database:** PostgreSQL with Prisma.

## Setup

Run the entire stack with one command:

```bash
docker compose up
```

## Structure

- `/client` - Frontend React application
- `/server` - Backend Express application
- `/docs` - Architecture, decisions, and deployment documentation
